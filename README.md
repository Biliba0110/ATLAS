# HomeLab IPAM

Локальный MVP-проект для учета подсетей, именованных диапазонов и IP-адресов в домашней лаборатории без автоматизации и сетевого сканирования.

## Что уже есть в версии 0.1

- добавление подсетей с CIDR и выделенным пулом адресов
- добавление групп диапазонов внутри подсети, например `hypervisor 2-4` или `VM 5-19`
- ручное добавление устройств: имя, IP, необязательный MAC, тип, комментарий
- проверка занятости IP на основе сохраненных записей
- поиск по IP, MAC, имени устройства, типу, подсети и группе диапазона
- экспорт в `JSON` и `CSV`
- импорт из `JSON` и `CSV`
- веб-интерфейс с таблицами устройств, подсетей и диапазонов
- общее хранение данных в `SQLite`, доступное всем клиентам, которые открывают один и тот же сервер

## Запуск

Запуск через встроенный Python-сервер приложения:

```bash
python3 server.py
```

После этого откройте `http://localhost:4173`.

Для доступа с других устройств в сети:

- запусти сервер на машине, которая доступна в LAN
- открой `http://<IP_этой_машины>:4173`
- данные будут общими, потому что они лежат в одной SQLite базе на сервере

## Где хранится база

- база создается автоматически в `data/ipam.db`
- сам репозиторий остается "чистым", потому что `data/` добавлена в `.gitignore`
- можно удалять файл базы целиком, чтобы получить полностью пустую инсталляцию
- можно переносить только код без `data/ipam.db`, а потом наполнять новую базу после разворачивания

## Формат данных

### Подсети

- `name` — имя подсети
- `cidr` — сеть в формате `192.168.10.0/24`
- `rangeStart` / `rangeEnd` — границы пула адресов
- `note` — комментарий

### Устройства

- `name` — имя устройства
- `ip` — IPv4 адрес
- `mac` — необязательный MAC в формате `AA:BB:CC:DD:EE:FF`
- `type` — `server`, `container`, `iot`
- `subnetId` — идентификатор подсети, если выбран явно
- `note` — комментарий

### Группы диапазонов

- `name` — имя группы, например `hypervisor`
- `subnetId` — подсеть, внутри которой живет диапазон
- `rangeStart` / `rangeEnd` — границы диапазона
- для `/24` можно указывать только последний октет, например `2` и `4`
- `note` — комментарий

## Импорт и экспорт

- `JSON` хранит полный снимок проекта: подсети, группы диапазонов и устройства
- `CSV` экспортируется раздельно: отдельно для подсетей, диапазонов и устройств
- при импорте приложение предлагает заменить текущие данные или объединить их
- импорт и удаление теперь работают уже с серверной базой, а не с локальным браузерным хранилищем

## Ограничения MVP

- проверка занятости IP работает только по данным, внесенным вручную
- нет автообнаружения устройств, DHCP-интеграции и сканирования сети
- диапазоны сейчас задаются вручную и не поддерживают вложенность
- редактирование записей пока не добавлено, вместо этого доступно удаление и повторное создание
- если несколько пользователей меняют одни и те же записи одновременно, полноценного разрешения конфликтов пока нет
