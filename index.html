Дополнительно

О программе

ATLAS

Локальный IPAM для домашней лаборатории: подсети, диапазоны, ручной учет устройств, ping-проверка занятости, история IP и live-обновления.

Назначение

Что делает ATLAS

ATLAS помогает видеть, какие IP заняты в подсетях, как разбиты диапазоны внутри пула и какие изменения происходили с адресами устройств. Проект рассчитан на self-hosted использование в сети home lab.

Импорт и экспорт

Форматы данных

JSON подходит для полного снимка состояния. CSV удобен для табличной работы и ручного редактирования: выгрузки разделяются по сущностям и подготовлены для чтения в Excel.
